# Marken-Material Flaconella

Dieser Ordner wird **nicht** auf den Webserver hochgeladen (siehe `.deployignore`).
Er sammelt die Quelldateien der Marke, damit sie neben dem Shop-Code versioniert sind.

| Datei | Inhalt |
|---|---|
| `logo-hell.jpeg` | Logo olivgrün/gold auf Weiß, 2048×1228 – für helle Untergründe |
| `logo-dunkel.jpeg` | Logo auf Schwarz, 1600×960 – für dunkle Untergründe |
| `logo-transparent.png` | Logo freigestellt, 1600×960 – für Overlays, Social Media, Druck |
| `marken-kontext.md` | Farben, Stil, Positionierung, Tagline (Mai 2026) |
| `aufbauplan-2026-05.md` | Ursprünglicher Aufbauplan der Marke (Mai 2026); Preise darin sind überholt, aktuell gilt der Shop |

Die ausführlichen Markentexte (Story, Ton, Produkttexte, Instagram-Bausteine) liegen im
Friday-Vault unter `03 Resources/Flaconella/`.

Für die Website selbst wird `images/logo.png` verwendet.
